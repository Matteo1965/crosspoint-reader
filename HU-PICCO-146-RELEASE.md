# CrossPoint Hungarian Edition – BOOX Picco HU-PICCO-146

## Magyar

A CrossPoint 2.0.0 alapjaira épülő, kifejezetten a **BOOX Picco** készülékhez készült magyar nyelvű firmware.

### Főbb funkciók és javítások

- Magyar nyelvű felhasználói felület és olvasómenük.
- Kiterjesztett magyar szóelválasztás és az összetett szavak elválasztásának javítása.
- Magyar olvasáshoz finomított tipográfiai és szövegmegjelenítési beállítások; .cpfont és TTF betűkészletek támogatása.
- A hivatalos BOOX Picco Beta v2-ből átvett fontletöltési javítás: a letölthető betűkészletek katalógusa és a GitHubról történő telepítés ismét működik.
- Könyvjelző hozzáadása és eltávolítása a jobb felső sarokban lévő ikonnal, külön megerősítő üzenet nélkül.
- Az „Indexelés...” jelzés megjelenítése a fejezetek előkészítésekor, előre- és visszalapozás esetén is.
- A .cpfont betűkészletadatok gyorsítótárának megőrzése fejezetváltáskor.
- A Névjegy oldalon a **HU-PICCO-146** verzióazonosító látható.

### Letöltés és telepítés

Töltsd le a **HU-PICCO-146-firmware.bin** fájlt az alábbi mellékletek közül, majd telepítsd a BOOX Picco kompatibilis firmware-frissítési eljárásával. A GitHub Actions ZIP-csomagot nem lehet közvetlenül firmware-ként telepíteni; szükség esetén előbb ki kell bontani a `firmware.bin` fájlt.

Frissítés előtt ajánlott biztonsági mentést készíteni a könyvekről és a beállításokról. A **HU-PICCO-146-SHA256.txt** tartalmazza a firmware SHA-256 ellenőrzőösszegét.

### Kompatibilitás

**Kizárólag BOOX Picco készülékhez!** Más CrossPoint-kompatibilis olvasóra ezt a firmware-t ne telepítsd.

## English

A Hungarian-language firmware for the **BOOX Picco** e-reader, based on CrossPoint 2.0.0.

### Features and fixes

- Hungarian user interface and reader menus.
- Extended Hungarian hyphenation, including improved handling of compound words.
- Typography and text layout refinements for Hungarian reading, with support for .cpfont and TTF fonts.
- Font download fix adopted from the official BOOX Picco Beta v2: the downloadable font catalogue and GitHub-hosted font installation work again.
- Add or remove bookmarks using the top-right dog-ear icon, without a redundant confirmation popup.
- Displays the “Indexing…” indicator while preparing chapters, including forward and backward chapter transitions.
- Retains the .cpfont font metrics cache across chapter changes.
- The About screen displays the **HU-PICCO-146** firmware version.

### Download and installation

Download **HU-PICCO-146-firmware.bin** from the release assets below and install it using the BOOX Picco-compatible firmware update procedure. A GitHub Actions ZIP archive is not itself a flashable firmware image; extract `firmware.bin` first if using an Actions artifact.

Back up your books and settings before updating. **HU-PICCO-146-SHA256.txt** contains the firmware SHA-256 checksum.

### Compatibility

**BOOX Picco only.** Do not install this firmware on other CrossPoint-compatible e-readers.
